# Optional orchestration profile

This is the current, simplified recipe evolved from the Sol-led Slopdex
campaign. It does not grant tools, permissions, model access or extra capacity,
and Slopdex does not require these instructions.

- [`global-AGENTS.sample.md`](global-AGENTS.sample.md): compact mode selection.
- [`aggressive-recursive-orchestration`](skills/aggressive-recursive-orchestration/SKILL.md): useful decomposition and deliberate model routing.
- [`adaptive-orchestration`](skills/adaptive-orchestration/SKILL.md): ownership, native waiting, evidence and safe iteration.
- [`campaign-dag-orchestration`](skills/campaign-dag-orchestration/SKILL.md): one compact plan for work sharing an integration checkpoint.

Install the three skill directories through your usual Codex skill workflow,
including the campaign reference. Merge the sample into your existing
instructions rather than overwriting unrelated preferences. Nothing here
changes your settings automatically.

Then open a project and give it an ordinary task. No role activation phrase is
needed. The model can work directly, branch, or add a coordinator when that
helps; there is no required hierarchy or agent count.

Authorized offline repairs continue without another permission round.
Acceptance still binds exact bytes; external actions, safety stops and user
pauses retain their boundaries. See [what changed](EVOLUTION.md). Earlier
recipes remain in Git history, not in the current installable bundle.

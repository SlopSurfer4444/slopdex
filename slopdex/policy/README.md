# Optional orchestration profile

These are the instructions used in the Slopdex field campaign. Review them
before adopting them. They do not grant tools, permissions, model access or
additional capacity on their own.

- [`global-AGENTS.sample.md`](global-AGENTS.sample.md) selects the working mode.
- [`skills/`](skills/) contains the four skills and their required references.

Install the individual skill directories through your usual Codex skill
workflow. Merge the global sample into your existing instructions rather than
overwriting unrelated preferences. The bundle does not modify your settings
automatically.

For a campaign, open the project and say:

> You are the parent architect for this project. Read and follow
> `$control-role-boundary`. Take the campaign to an honest result.

The parent chooses whether an operational coordinator is useful and creates
one itself. The role skill requires an explicit assignment; the decomposition
skills do not impose a minimum number of agents. Treat models, agent counts,
depth and routing as choices to evaluate against real work.

# Historical Sol orchestration profile

These are the instructions used in the Sol-led Slopdex field campaign, retained
for reproducibility of that working recipe. They do not grant tools,
permissions, model access or additional capacity on their own.

**Read [the 2026-09-05 evolution note](EVOLUTION.md) first.** The owner has chosen
to retire separate role initialization from the active recipe as Astra field
work begins. The snapshot below is not a requirement for using Slopdex and is
not a claim that the shared global cleanup has already completed everywhere.

- [`global-AGENTS.sample.md`](global-AGENTS.sample.md) selects the working mode.
- [`skills/`](skills/) contains the four skills and their required references.

If you deliberately want to reproduce the historical profile, review the
individual skill directories through your usual Codex skill workflow and merge
rather than overwrite unrelated preferences. The bundle does not modify your
settings automatically.

The historical explicit-role invocation was:

> You are the parent architect for this project. Read and follow
> `$control-role-boundary`. Take the campaign to an honest result.

That role shim required explicit admission and its parent reference constrained
routine execution to a separate coordinator. This restriction is one reason
for the new decision; do not read the old invocation as current mandatory
setup. Useful decomposition does not require a minimum number of agents, and
models, depth and routing remain choices to evaluate against real work.
